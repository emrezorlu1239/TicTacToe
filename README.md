# Tic Tac Toe (C#)

A simple **Tic Tac Toe** game built with **Windows Forms (C#)**.  
Playable by two players on the same computer, with a clean and interactive interface.

---

## 🕹️ Features

- Classic 3x3 Tic Tac Toe gameplay  
- Two-player mode on the same computer  
- Detects **win**, **draw**, and **invalid moves**  
- Easy to reset the game for a new round  
- Beginner-friendly and well-structured code  

---

## 🗂️ Project Structure

- `Form1.cs` – Main game logic and UI handling  
- `Program.cs` – Application entry point  
- `Properties` – Project settings and resources (icons, etc.)  

---

## ⚙️ How to Run

1. **Download the ZIP file** from GitHub.  
2. **Extract it** using any tool like WinRAR or 7-Zip.  
   - Make sure to **fully extract** the folder (do not run it directly from inside the archive).  
3. Open the project folder in **Visual Studio**.  
4. Click **Build → Start Debugging (F5)** to launch the game.  

---

## 🧰 Requirements

- Windows OS  
- **Visual Studio 2019 or later**  
- **.NET Framework 4.7.2+**  

---

## ⚠️ Notes

- All game logic is implemented using C# and Windows Forms.  
- Input validation ensures players cannot make invalid moves.  
- Code is simple and suitable for learning purposes.
